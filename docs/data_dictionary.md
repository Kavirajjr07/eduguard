# Data dictionary

The synthetic dataset uses a 10-point GPA scale (0.00–10.00).

- student_id: Unique institutional identifier.
- age: Student age in years.
- year_of_study: 1 to 5 with 6 for terminal progression cases.
- department: Academic department.
- attendance_pct: Attendance percentage.
- internal_marks: Internal assessment score.
- assignment_completion_pct: Submission completion rate.
- previous_gpa: Prior GPA on a 0.00–10.00 scale.
- current_gpa: Current GPA on a 0.00–10.00 scale.
- failed_subjects: Number of subjects with failing performance.
- study_hours_weekly: Hours of weekly self-study.
- commute_minutes: Travel time to campus.
- family_income_band: Socio-economic income band.
- first_generation_student: Binary indicator.
- scholarship: Binary indicator of scholarship support.
- fee_payment_delay_days: Number of delayed payment days.
- engagement_score: Composite activity and participation score.
- counselling_sessions: Number of counselling engagements.
- dropout_next_semester: Synthetic target label for demonstration.
